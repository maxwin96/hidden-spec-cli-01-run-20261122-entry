mend is one patch tool for every AI edit format: it applies unified diffs, SEARCH/REPLACE blocks, V4A patches, and JSON editor calls to a tree of text files, matching lines at three whitespace tiers, honouring CRLF and missing final line breaks, and writing every change or nothing at all.
## Run it
```sh
node main.ts [options] [PATCH]
```
